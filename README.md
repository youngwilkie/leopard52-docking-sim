# Leopard 52 — Grenada Docking Simulator

A twin-screw catamaran handling trainer set in St. George's Lagoon and Port
Louis Marina, Grenada. Built as a personal side project.

Open `index.html` — it is entirely self-contained (three.js is bundled, no
network access required).

The boat is a 2025 Leopard 52: 15.75 m LOA, 8.16 m beam, 1.70 m draft,
20,517 kg light, twin Yanmar 57 hp saildrives on a 6.01 m prop track.

Physics is a 3-DOF rigid body at 200 Hz: strip-theory hull forces per hull,
open-water propeller Kt/Kq curves, a diesel governor with flywheel inertia,
rudders that only get partial propeller-race coverage, windage, current,
shallow-water effects and bank suction.

No bow thruster. You steer with the throttles.
